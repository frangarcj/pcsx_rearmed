First public beta of **PCSX ReArcade**, a PS Vita emulator for Namco System 12 arcade games. It is built on PCSX-ReARMed and on Rinnegatamante's PCSX AwO frontend, and shows the games as 3D arcade cabinets on a game shelf.

## Games

Tested on a PS Vita:

- Soul Calibur
- Tekken 3
- Tekken Tag Tournament

Recognised but **not yet verified** (they use the same board without special hardware, so they may work; reports are welcome): Ehrgeiz, Fighting Layer, Libero Grande, Shin Nihon Pro Wrestling Toukon Retsuden 3, Mr. Driller, Aqua Rush, Super World Stadium '98, '99, 2000 and 2001, Tenkomori Shooting, Paca Paca Passion, Paca Paca Passion 2 and Special, Derby Quiz My Dream Horse, Kaiun Quiz.

Not emulated, and refused at load time: the light-gun games (Point Blank 2, Ghoul Panic, Golgo 13 and Golgo 13 Kiseki no Dandou), Techno Drive, Truck Kyosokyoku, Um Jammer Lammy NOW!, Attack Pla Rail and Kart Duel.

## Features

- Games load straight from MAME romset zips: split, merged or non-merged, with files found by CRC.
- 3D cabinet shelf, with each game's regional versions grouped together.
- Two renderers, chosen in the shelf's options: vitaGL (HD, the default) or NEON (exact PlayStation GPU output).
- Pause menu: restart, save states, options, and "Use as cabinet art" to take the cabinet's picture from the game.
- Arcade options: button layout, the board's test switch (service menu) and a sound volume boost.
- Soul Calibur runs at 58–60 fps; the busiest scenes dip slightly below 60.

## Install

1. Install `pcsx-rearcade.vpk` (title ID `PCRA00001`).
2. It needs `libshacccg.suprx` in `ur0:data/external/`.
3. Copy MAME romset zips to `ux0:data/pcsx-rearcade/roms/`. Cabinet art is optional: PNG files named after the set in `snap/` and `marquees/`.

No game data is included.

## Controls

- **Shelf:** left/right game, up/down version, Cross play, Square options, Select about, R rescan, Triangle exit.
- **In a game:** Start + Select pauses.
- **Arcade buttons** (changeable in the options): Square, Triangle, Cross and Circle are buttons 1–4, L1 and R1 are 5 and 6, Select inserts a coin, Start is start.

## Known limitations

- Beta: only the three games above have been tested on hardware.
- No artwork download yet; cabinet art comes from your own files or from "Use as cabinet art".
