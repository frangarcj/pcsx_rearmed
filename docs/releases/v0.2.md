PCSX ReArcade v0.2 adds **Namco System 10, Namco System 11 and Capcom ZN-1/ZN-2** to the PS Vita game shelf, alongside System 12 and PlayStation discs.

## New systems

- **Namco System 10:** prepared MEM(M)/MEM(N) profiles, MIPS DRC with bank/flash/NAND code invalidation, and SPU synthesis on a separate worker. Representative check: Mr. Driller 2.
- **Namco System 11:** prepared board profiles, MIPS DRC, type-1 PSX GPU support, C76/C352 sound on a separate worker, and EEPROM persistence. Representative checks: Tekken 2 and Soul Edge.
- **Capcom ZN-1/ZN-2:** prepared Capcom profiles, MIPS DRC with ROM bank invalidation, actual SIO/MCU devices, Z80/QSound on a separate worker, and EEPROM persistence. Representative Vita3K check: Street Fighter EX; generated checks cover both ZN generations.

The NEON executable uses **core 0 for main MIPS/DRC, core 1 for the GPU, and core 2 for SPU (System 10), C76/C352 (System 11), H8/C352 (System 12), or Z80/QSound (Capcom ZN)**. The sound CPUs retain their existing interpreters. Serial devices, main IRQs and synchronization remain on the main thread where required.

## Integration and fixes

- Prepared arcade folders appear on the shelf with their regional versions grouped together; incomplete profiles are rejected.
- Shared arcade button assignments, restart and board audio rates work across the four families.
- EEPROM images are stored as `<set>.arcade-nvram` in the frontend save directory, separately from the ROMs. Invalid installed images are preserved.
- Save states are hidden/rejected for boards whose complete state is not supported.
- Fixed mapped ZN ROM pages repeating the first page, ROM bank translation invalidation, and ARMv7 build portability issues.
- Incremental builds track renderer/thread configuration changes and relink the executable when its core archive changes.

## Install and add games

1. Install **`pcsx-rearcade.vpk`** over the existing app (title ID `PCRA00001`). The VPK includes both vitaGL and NEON executables.
2. Keep `libshacccg.suprx` in `ur0:data/external/`.
3. System 12 continues to accept supported MAME romset ZIPs. For the new systems, prepare your own media on a computer with `scripts/prepare_system10_board.py`, `scripts/prepare_system11_board.py` or `scripts/prepare_capcom_zn_board.py`; each script documents its arguments with `--help`.
4. Copy each complete prepared folder, including `board.ini` and every region file, directly into `ux0:data/pcsx-rearcade/roms/`, then rescan the shelf with R. Raw MAME ZIPs for System 10, System 11 and Capcom ZN are not loaded directly by this release.
5. Select NEON in the game's renderer options to use the core layout described above.

No ROMs, BIOS images, firmware or other game data are included. Existing controls remain: Select inserts a coin, Start starts, and Start + Select opens the pause menu; arcade buttons can be remapped in the options.

## Validation and limits

This remains a beta. Compilation of both Vita executables is required before GitHub publishes the package. Local instruction-driven tests cover DRC banking, self-modifying code, mapped inputs, serial/EEPROM timing, sound-worker synchronization and profile switching. Serial/threaded audio comparisons match exactly in the tested cases. Street Fighter EX completed a 1800-frame, 42-input Vita3K replay with DRC and both workers, with zero board faults or audio errors.

The newly added systems have representative native and Vita3K coverage; this is not a claim that every listed game works on physical Vita or runs at full speed. Vita3K has shown an intermittent host condition-variable exception and a host cleanup crash after completed runs. System 10 mutable flash/NAND persistence and complete save states for the new boards remain pending. Other arcade families present in native development tools are not advertised as supported by this Vita release.
