PCSX ReArcade v0.3 loads **Namco System 10, Namco System 11 and Capcom ZN games straight from MAME ROM zips**, as System 12 already did. No computer-side preparation step is needed any more.

## What's new

- **Raw MAME zips for System 10, System 11, Capcom ZN and System 12.** Copy the zips into `ux0:data/pcsx-rearcade/roms/` and rescan the shelf with R. Merged, split and non-merged sets all work, zip names do not matter (files are found by CRC32 and size), and the BIOS and sound sets a game needs (`namcoc76.zip`, `coh1000c.zip`, `qsound.zip`...) are found next to it. 90 sets are recognised from zips: 12 System 10, 35 System 11 and 43 Capcom ZN, besides the System 12 list. A missing or corrupt file is named in the log.
- **Capcom ZN BIOS option.** The ZN-1 games that ship two BIOS files (Street Fighter EX, Star Gladiator, Tech Romancer...) take Japan or English (debug) from the new "Capcom ZN BIOS" option, in the selector and the pause menu. Auto is Japan. If your zips only hold the other BIOS, the game uses it.
- **System 10 flash/NAND persistence.** What a System 10 game writes to its flash or NAND is saved as `<set>.arcade-flash` in the save folder (only the changed 16 KiB blocks) and restored on the next start.
- **Dunk Mania, Dunk Mania (Japan) and Prime Goal EX** (System 11) now load: their ROM definitions rewrite bytes that are already loaded, which the preparation script used to refuse.
- **Faster launches.** The shelf keeps the index of your zips while they do not change, so starting a game after the scan does not read every zip again.
- Prepared folders (`scripts/prepare_*_board.py`) still work, and the shelf prefers one to a zip of the same set.

## Install

1. Install **`pcsx-rearcade.vpk`** over the existing app (title ID `PCRA00001`). It includes both the vitaGL and NEON executables.
2. Keep `libshacccg.suprx` in `ur0:data/external/`.
3. Copy your own MAME zips into `ux0:data/pcsx-rearcade/roms/`.

No ROMs, BIOS images, firmware or other game data are included.

## Validation and limits

This remains a beta. The zip loaders were checked on a Mac against synthetic zips (the right file sizes and CRC32 values, random content): for all 90 sets the board package the console builds is byte-identical to the one the preparation scripts write, and the production core loads, reloads and unloads a game of each family. **No real game has been started from a zip on a Vita for this release**, and no real System 10 game has written to its flash yet. The Vita package builds without errors.

Known limits: only what the preparation scripts accept is listed (System 10 sets with extra hardware, System 11 sets that need a CHD and ZN BIOS-only sets are not); the ZN BIOS choice applies to the next game started; opening your rom folder reads the directory of every zip once per change. See `docs/arcade-romsets.md`.
