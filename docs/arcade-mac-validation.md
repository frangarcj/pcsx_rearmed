# Representative arcade board validation on Mac

The current goal is to run representative games across the PlayStation-derived
arcade board families. A ROM/profile parser, a synthetic guest or a passing
component test does not establish game compatibility. A passing row requires
observed player gameplay, exercised inputs, recorded device diagnostics and
appropriate sound evidence; title/demo/installation screens are recorded as
intermediate results. Physical Vita is outside this Mac pass.

Other Sony ZN daughterboards (including Acclaim, Atari and Video System) must be
reviewed against the complete source inventory before claiming coverage of the
entire `zn.cpp` family. Regional clones do not substitute for distinct CPU/GPU,
sound or peripheral configurations. Retail PlayStation is inventoried separately
from the arcade boards.

## Current next checks

- Psychic Force: player-start watchdog at PC `800f8564`, with interrupts disabled
  (`SR=40000404`) inside a VSync wait; late coin replay reproduces it. Source SPU
  DMA completion alone does not resolve it. The no-input presentation run has no
  watchdog requests. Keep the EEPROM generated by the native service exit.
- Hyper Athlete: idle Sony serial status, CXD8514Q type-2 GPU, EEPROM word order
  and prepared CHD filename are corrected from pinned MAME source. The original
  raw EEPROM remains hash-checked; the device receives byte-pair-normalized words,
  matching independent MAME NVRAM. The native player-start run stalls with DRQ
  high after its DMA request is exhausted. Latest diagnostic: NCR command `90`,
  phase `0`, count `28/28`; last request is four words. Inspect the SCSI command
  and data-phase handshake against the source. Authentic ARM64 DRC still uses
  console serial MMIO handlers and is not a passing runtime configuration here.
- After these two player checks, compose FX1Z and Tecmo using their real source
  maps, then proceed through Raizing and the remaining Konami families.

No missing firmware, keys or CHDs have been substituted. Original BIOS/ROM/EEPROM
